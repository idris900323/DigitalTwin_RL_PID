\subsection{Kd-bound check (post hoc)}\label{app:kdbound}
The extended-search constants of Section~\ref{sec:posthoc} sit at the $K_d$ bound of $2$, which was set for encoder-noise reasons, so the bound might have been limiting them. We repeated the extended-constant search with the $K_d$ upper bound raised to $4$ (constants only; the learned policy keeps its training environment), deriving the constants on validation seeds only, and evaluated once on a fresh range, seeds $90000$--$90099$ (ledger L14). Table~\ref{tab:kdbound} gives the paired differences.

\textbf{Do the constants move off the bound?} In the static regime the search returns the same constant ($K_p=\KdBoundStaticKpfour$, $K_d=\KdBoundStaticKdfour$, validation return $\KdBoundStaticValFour$ as before), i.e.\ with the bound at $4$ no better point was found, so the optimum found there is not set by the bound. With payload and target changes it moves to $K_p=\KdBoundChangesKpfour$, $K_d=\KdBoundChangesKdfour$ (validation $\KdBoundChangesValFour$ against $\KdBoundChangesValTwo$), and out of distribution to $K_p=\KdBoundOodKpfour$, $K_d=\KdBoundOodKdfour$ (validation $\KdBoundOodValFour$ against $\KdBoundOodValTwo$), below the old bound. The test differences between the two extended constants are $\KdBoundStaticBestConstantExtKdfourBestConstantExtMed$, $\KdBoundChangesBestConstantExtKdfourBestConstantExtMed$ and $\KdBoundOodBestConstantExtKdfourBestConstantExtMed$ median return (static, changes, ood), i.e.\ negligible.

\textbf{Does policy minus extended constant change?} Against the bound-4 constant it is $\KdBoundStaticPpoBestConstantExtKdfourMed$ [$\KdBoundStaticPpoBestConstantExtKdfourLo$, $\KdBoundStaticPpoBestConstantExtKdfourHi$] (mean $\KdBoundStaticPpoBestConstantExtKdfourMean$, IQR [$\KdBoundStaticPpoBestConstantExtKdfourQone$, $\KdBoundStaticPpoBestConstantExtKdfourQthree$]) in the static regime, $\KdBoundChangesPpoBestConstantExtKdfourMed$ [$\KdBoundChangesPpoBestConstantExtKdfourLo$, $\KdBoundChangesPpoBestConstantExtKdfourHi$] with changes (not distinguishable from zero) and $\KdBoundOodPpoBestConstantExtKdfourMed$ [$\KdBoundOodPpoBestConstantExtKdfourLo$, $\KdBoundOodPpoBestConstantExtKdfourHi$] (mean $\KdBoundOodPpoBestConstantExtKdfourMean$, IQR [$\KdBoundOodPpoBestConstantExtKdfourQone$, $\KdBoundOodPpoBestConstantExtKdfourQthree$]) out of distribution, against $\KdBoundOodPpoBestConstantExtMed$ for the bound-2 constant there. The conclusion is unchanged: most of the policy's gain is a better constant, and a small residual of the same size remains in the static and out-of-distribution regimes, which we do not attribute to adaptation. The out-of-distribution interval now only just excludes zero, so that residual should not be read as established. Caveats: the search started from the bound-2 constant with a limited Nelder--Mead budget and may have stopped in a local optimum, and a larger $K_d$ increases noise amplification, which the return penalises only through its chatter term.
